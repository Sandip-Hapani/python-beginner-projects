# Famous Math Problem Simulation

This folder contains Python projects that simulate classic, well-known probability and logic puzzles.

Each project demonstrates how a famous mathematical problem works using code, and then uses simulation to show the actual probability outcomes over many trials.

## What is this folder for?

The `Famous-Math-Problem-Simulation` folder is a collection of beginner-friendly Python examples that:

- explain a classic math or probability puzzle
- simulate the puzzle with repeated trials
- compare theoretical probability with empirical results
- help learners understand how randomness and strategy affect outcomes

## Problems listed here

- `Monty-Hall-Problem/`
  - Simulates the Monty Hall problem, a probability puzzle based on a game show scenario.
  - Compares the win rate of staying with the original door versus switching after the host reveals a goat.
  - The problem is named after Monty Hall, the host of the game show "Let’s Make a Deal".
  - It was first described in the statistical literature by Steve Selvin in 1975 and later popularized by Marilyn vos Savant in 1990.
  - Reference: https://en.wikipedia.org/wiki/Monty_Hall_problem

## Why these problems are useful

These simulations make abstract probability ideas easier to understand by showing how often each strategy succeeds in practice. They also highlight surprising results that are counterintuitive at first, such as why switching doors in the Monty Hall problem is usually the better choice.

## How to use these projects

Open a project folder and read its own `README.md` for details. Each project typically includes a small Python script you can run from the command line and experiment with different numbers of trials.
